# 故障处理快速决策 S.O.P

本文档作为快速决策参考，列出高频故障的症状 → 判断 → 行动的对应关系。
详细逐步排查见 ops_manual.txt（常见故障处理 SOP）。

## 1. 服务响应超时 / 5xx
- 症状:API 大量 5xx、响应缓慢
- 判断:数据库连接池满?下游服务异常?
- 行动:
  1. 先查健康检查与连接池占用
  2. systemctl restart <service>
  3. 重启后仍异常 → 查资源占用，考虑扩容

## 2. 内存溢出
- 症状:日志出现 OutOfMemoryError
- 判断:JVM 堆不足 或 内存泄漏
- 行动:增大 -Xmx → 观察 → 仍频繁则扩容/排查泄漏点

## 3. 服务启动即失败（容器内）
- 症状:容器反复 CrashLoopBackOff
- 判断:应用启动参数错误、探针配置过严、启动依赖未就绪
- 行动:见 k8s_ops_manual.txt「Pod 排障」章节

## 4. 磁盘写满
- 症状:写日志/写 DB 报 No space left
- 行动:清理 /var/log 旧日志 → 扩容磁盘分区
