MySQL 常见故障排查手册

一、连接失败
1. 检查服务状态：systemctl status mysql
2. 检查端口是否监听：netstat -tlnp | grep 3306
3. 防火墙放行：ufw allow 3306/tcp
4. 用户权限：SELECT User,Host FROM mysql.user WHERE User='root';
5. 密码错误：重置密码 ALTER USER 'root'@'localhost' IDENTIFIED BY 'new_password';

二、慢查询
1. 开启慢查询日志：SET GLOBAL slow_query_log = ON;
2. 设置阈值：SET GLOBAL long_query_time = 1;
3. 分析日志：mysqldumpslow -s t /var/log/mysql/slow.log
4. 常见原因：缺失索引、不必要的 SELECT *、JOIN 条件错误

三、磁盘空间不足
1. 检查数据目录大小：du -sh /var/lib/mysql
2. 检查 binlog 空间：SHOW BINARY LOGS;
3. 清理过期 binlog：PURGE BINARY LOGS BEFORE NOW() - INTERVAL 3 DAY;
4. 考虑扩容或调整 expire_logs_days

四、主从复制延迟
1. 检查 Slave_IO_Running、Slave_SQL_Running：SHOW SLAVE STATUS\G
2. 网络延迟：ping 主机
3. 磁盘 I/O：iostat -x 1
4. 事务太大：检查长事务，拆分批量更新

五、InnoDB 锁等待
1. 查看当前锁事务：SELECT * FROM information_schema.INNODB_LOCKS;
2. 查看等待事务：SELECT * FROM information_schema.INNODB_LOCK_WAITS;
3. 常见原因：忘记提交事务、批量更新未分批、序列号冲突

六、备份与恢复
1. 逻辑备份：mysqldump -u root -p --all-databases > backup.sql
2. 物理备份：xtrabackup --backup --target-dir=/backup
3. 恢复测试：定期在测试环境执行恢复演练

七、监控指标
- Threads_connected：活跃连接数
- Queries_per_sec：QPS
- Innodb_buffer_pool_wait_free： buffer pool 等待次数
- Handler_read_rnd_next：全表扫描次数
